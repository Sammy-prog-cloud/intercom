# IntercomSwap — Trac Protocol Fork

A combined **token swap DEX** + **peer-to-peer messaging** app built on the Trac Protocol.

## 🔗 Trac Address

```
trac1p7yqla5zmzlj2ssjvpfa4xpcx7xrwt3qzl4c8n4qhqwv3k2zu6ls5z9d6h
```

## Features

- **⇄ Swap** — Instant token swaps (BTC, TRAC, ETH, USDT) with real-time rate display, price impact, and routing
- **✉ Messages** — On-chain P2P messaging tied to your Trac address
- **◈ Portfolio** — Track token balances, P&L, and sparkline charts

## Tech Stack

- Pure HTML/CSS/JS — no framework dependencies
- Canvas-based sparkline charts
- Fully responsive layout

## Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/intercomswap
cd intercomswap
open intercomswap-app.html
```
